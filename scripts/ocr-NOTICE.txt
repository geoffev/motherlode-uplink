language data. These components are credited to their upstream authors.

The runtime is built from the pinned sources described in SOURCE-MANIFEST.json,
using the recipe in scripts/build-ocr.ps1 in the Motherlode Uplink repository.
No upstream source files are modified. Optional image codecs, the legacy OCR
engine, network/archive support, training tools, OpenMP and the graphics viewer
are disabled. The app
passes grayscale pixels and model bytes directly to the native API. Both
OCR libraries are linked statically into the app; no OCR executable or DLL is
bundled. The OCR Microsoft C/C++ runtime is linked statically.

No UB Mannheim/MSYS2 binaries or GPL/LGPL libraries are included in this OCR
bundle. Microsoft runtime libraries are used under the Visual Studio Build Tools
license. Microsoft STL header code is Apache-2.0 WITH LLVM-exception, whose
compiled-code exception permits redistribution of embedded object code.
  https://github.com/microsoft/STL/blob/main/LICENSE.txt
